
# Torque
Torque is a end-to-end encrypted decentralized messaging platform

feel free to contribute


## details

encryption and key exchange:
X3DH with double ratchet

decentralized:
every client sends any data it wants to all of the servers.
no one soley controls any server.
every server is run by other people.

## Using

run setup.ps1 or setup.sh

to create 3 clients
first 2 are tui clients
the last one is the kivy client
simply navigate into the directory and run main.py to start the client


to run the server simply run the main.py in the server directory that you would like to run


put any servers you want to run in the server list
the ones here are for example only.
